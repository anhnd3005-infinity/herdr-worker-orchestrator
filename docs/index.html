Battle-Tested Innovations

5 Superpowers You Won't Find Elsewhere

Engineered specifically to solve real failure modes discovered during deep empirical testing.

Superpower #1 Zero Workspace Pollution

Git Worktree Isolation (`--isolation worktree`)

Dispatching multiple workers into the same folder destroys codebases. Herdr Worker Orchestrator spins up isolated git worktrees on dedicated branches (`task/TASK-xxx`). Workers never overwrite Claude's active files, enabling true parallel multi-agent development.

// Clean isolated tree architecture:
Project/
├── main worktree ← Claude works here
├── .worktrees/TASK-001 ← Worker 1 (agy)
└── .worktrees/TASK-002 ← Worker 2 (codex)
Superpower #2 State Machine

Stateful Task Ledger & Crash Recovery

Every task lives in .agents/tasks/TASK-xxx.json with lifecycle state transitions. If Claude restarts or context compacts, herdr plugin action invoke resume queries live Herdr agents and resumes work with zero loss.

Survives session compactions
Superpower #3 Enforced Verification

Diff-Enforced Review Policy

AI workers frequently hallucinate success. Our reviewer subagent is strictly forbidden from reading worker self-reports. Reviewers only inspect git diff, run build scripts, and verify test assertions before granting PASS status.

Evidence before assertions always
Superpower #4 & #5 Smart Heuristics

`stalled = UNKNOWN` & Zero Permission Blocks

Herdr error agent_prompt_stalled does not mean fail. Our script inspects terminal transcripts for delivery markers before deciding to wait vs retry. Additionally, automatic injection of --dangerously-skip-permissions and --add-dir prevents agents from hanging on interactive prompts.

Old Way (Blind Failure)
agent_prompt_stalled ➔ Abort task ➔ User frustrated
Our Way (Intelligent Inspection)
stalled ➔ Read transcript ➔ Found marker ➔ Wait & Pass!
